## 0. 结论

**1. 比例：按 11/15 方案自己的规则重算，只有两处变化。**

- **规则**：估值便宜且价格相对低位 → 加配；估值贵且价格相对高位 → 减配；MU 因周期高点标记减配。
- **NVDA 加配仍成立**：远期 P/E 约 10.0 倍，7 家里最低；距 52 周收盘高点 −39.5%。
- **MU 减配仍成立**：周期高点标记，和价格无关。
- **MSFT 减配不再成立**：距高点 −12.1%，已经不算"相对高位"（规则要求离高点 10% 以内且在 200 日线上方）。按规则回到长期比例 8%。
- **TSM 新出现加配信号**：11/13 以来跌 16.3%，估值排第二便宜，价格相对低位。方案没定 TSM 的加配幅度，这里先不动。
- **结果**：NVDA 的加配只剩 MU 让出的 1.5 个百分点，所以 NVDA 12.5% → 11.5%，MSFT 7% → 8%，其余不变。见 §2 的四个版本。

**3. 怎么用。**

- K 线只影响什么时候下单，不改比例。比例由估值和风险决定（§1）。
- 历史证据不支持"等 K 线确认能多赚"：
  - 11/15 对这 8 只做过检验（2022-11 至 2026-08 每月末，`claude_analysis_20261115/out/summary.json`）。离 52 周高点跌得越深的股票，之后 3 个月的相对表现反而越好：15 个不重叠样本的排序相关 0.23，t = 3.1。但 1 个月不显著（t = 1.6）。
  - 同一检验里，"在 200 日线下方"的股票之后 1 个月略差，不显著（多空 t = −1.8）；12-1 动量没有预测力。
  - PR #14 §4b 显示，指数层面等更低价格再买平均不占便宜。
  - 所以这里的"暂缓"只是为了不在一根大阴线里接飞刀、少后悔，不是在预测收益。代价是可能错过像 11/23 那样的单日大反弹；按上面的 3 个月结果，跌得深的几只等太久反而吃亏。
- 折中做法：
  - "可买"和"观察"组按计划买。
  - "暂缓"组先买一半，另一半等确认再买：某天收盘站上前一天的最高价，并且当天没有再创新低。
  - 最晚 12/14 前买完，不无限期等。

## 1. K 线规则（`entry_check_20261125.py`）

| 代号 | 含义 | 定义 |
|---|---|---|
| T1 | 下跌趋势 | 价格 < 20 日均线 < 50 日均线 |
| T2 | 新低 | 低于前 60 个交易日最低收盘价，或盘中低于前 20 个交易日最低价 |
| T3 | 反弹失败 | 11/20 收盘到 11/23–24 最高收盘的反弹回吐 ≥ 61.8%，或跌回 11/20 收盘价下方 |
| T4 | 大跌日 | 今天跌幅 ≥ 4% |
| T5 | 更高的高点 | 价格高于 11/20 之后的最高收盘价 |

- **暂缓** = T1 且（T2、T3、T4 至少一项）且不满足 T5。
- **可买** = T2、T3、T4 都不成立，且（不满足 T1 或满足 T5）。
- **观察** = 其余。

这些是常见的技术分析定义，没有在这 12 只股票上回测过。

## 3. 数据与局限

- **数据来源**：
  - 11/13 以前用 GPT 价格文件（哈希与 GPT manifest 一致）。
  - NVDA、MSFT、GOOGL、AMZN、META、TSM 的 10/27–11/25 日线来自 FMP，和 GPT 文件重叠的 14 个交易日完全一致。
- **AVGO、MU、VTI、BRK-B、XLV 数据不全**：FMP 当前套餐不给这几只的报价和日线，只能拿到今天价格和昨天收盘。
  - AVGO 和 VTI 的 11/16–11/20 日线来自 stockanalysis 页面（经 WebFetch 转录），和 GPT 文件在重叠日核对一致；两者都缺 11/23。
  - MU、BRK-B、XLV 缺 11/16–11/23 的日线。这些标的的 RSI/MACD 留空。
  - MU 的"新低"判断可能偏宽：11/20 当天 MU 收盘价不知道，那天可能更低。
- **估值**：用 11/16 的一致预期 EPS，只随价格缩放；NVDA 11/17 财报之后的预期上修没有计入。上修会让 NVDA 更便宜，不改变结论。
- **均线核对**：6 只有 FMP 报价的股票，自算 200 日线和 FMP 的 priceAvg200 差距都在 1% 以内（gate）。
