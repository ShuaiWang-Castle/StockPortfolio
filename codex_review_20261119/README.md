## 关键分歧怎样影响判断

1. **ANT 的股数、现金和估值锚点。** 424B4 的发行价稀释股数情景为 18.13759B 股；逐项重建的发行后备考现金及短投 $232.351B，已计及 RSU 代扣税。按 Claude 同价、同一组 DCF 假设，只修正 EV，隐含增速从 22.20%–31.47% 变为 22.31%–31.59%；改用 GAAP 季度年化收入、可兑现的现金流与新的利润率区间，才显著改变要求。Ritter 表 18d 的 −15.4pp 属于按发行价买入的 P/S>40 子样本，按首日收盘买入的同类子样本是 −58.5pp。用哪套股数和哪日价格归组会改变历史参照。[估值、DCF、解禁及历史分组](ANT.md) · [SEC 最终招股书](https://www.sec.gov/Archives/edgar/data/2130357/000162828026074944/anthropicpbc-424b4.htm) · [Ritter 表 18d](https://site.warrington.ufl.edu/ritter/files/IPO-Statistics.pdf)
2. **ANT 的风险预算。** Claude 的中心风险模型可复现。但用新资金买入，ANT 与买入前 GOOGL 的风险贡献相等，对应 3.73%；与同一买入后组合中的 GOOGL 相等，对应 3.46%。我以单名压力损失约束仓位，并把高相关压力与常态协方差并列。即使没有直接 ANT，Amazon、Alphabet 两条股权渠道已经使原拟议组合间接关联 ANT。[风险公式、三种资金来源与两种 NVDA 分支](PORTFOLIO.md)
3. **NVDA 的规则事实与适用范围。** Kress 在电话会明确提及新规并维持上调的增长展望；Q4 指引不含中国数据中心计算收入，不能证明第三国渠道没有受限。规则生效与公司量化收入损失是两件可分别核对的事。截至此次检索，EDGAR 列出的最新 10-Q 仍是 Q2。Q3 使用 11/17 的 8-K、CFO 说明和电话会；新 10-Q 公布后应补核附注。[正式规则](https://www.federalregister.gov/documents/2026/11/19/2026-23529/addressing-remote-access-to-advanced-semiconductors) · [NVIDIA 8-K](https://www.sec.gov/Archives/edgar/data/1045810/000104581026000088/nvda-20261117.htm) · [逐条判断](EQUITIES.md)
4. **已采纳方案的证据。** Vanguard 9/30 的七个发行人原始权重均核实。独立算得 Hybrid 未取整 AI 袖 47.051%，取整后三年季度再平衡实现波动 17.614%；NVDA 集中度下降的结论成立。回撤择时信号对历史抽样起点敏感，三个起点的 t 值分别为 3.08、1.18、1.13。已采纳权重继续以根目录机器可读方案为准。[构造、历史信号和季度脚本缺口](PORTFOLIO.md) · [机器可读方案](../current_plan.json)
