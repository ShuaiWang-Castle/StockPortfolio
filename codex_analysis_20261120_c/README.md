## 用已经赚到的现金交叉核对

在同一 12% 要求回报、3% 永续增长下，从实际 TTM FCF 每股 $6.14 出发，要支撑现价，前五年每股 FCF 需年均增长 **17.6%**。另取首年 FCF 增长 50% 这一主观假设，随后四年每年增长 10%、15%、20% 时，得到今天的价值 **$127、$148、$172**。这是对现金增长持续性的敏感性分析。公司 75% 的框架针对 FY28 收入。研究把公司 FCF 当作股东可用现金的近似，固定股数，未另加存量证券或净现金价值；战略投资需要额外现金、股权激励的经济成本或担保赔付均会改变结果。[历史现金流](https://www.sec.gov/Archives/edgar/data/1045810/000104581026000088/q3fy27pr.htm) · [反向 DCF 与情景输出](out/summary.json)

下次财报优先核对 Q4 收入能否落在 $130B ±3%、毛利率能否落在 71%–72%，以及应收回款。公司口径 DSO 从 60 天升到 64 天，CFO 提及部分客户的付款条款及 Rubin 出货时点。若持续延长并拖累现金，估值中上调现金转换率的依据会减弱。若大客户回款改善且 FY28 框架持续兑现，则应重算偏保守的增长假设。[CFO 说明，第 4–5 页](https://s201.q4cdn.com/141608511/files/doc_financials/2027/Q327/Q3FY27-CFO-Commentary.pdf)
