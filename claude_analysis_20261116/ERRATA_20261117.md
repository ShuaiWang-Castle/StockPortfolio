# 勘误（2026-11-17）：关于"黄仁勋策划回归"的说法

## 原文

- `README.md` §0.1、§1，以及根目录 README 的 11/16 一节，写的是"没有查到可信报道"。
- 理由是："回归"报道指的是 11/9–11/10 他回总部开会，发生在辞职之前。

## 错在哪里

FT 在 11/15（周日）报道了这件事，路透社等广泛转载：

- 黄仁勋在考虑回归 CEO，已和亲信讨论；
- 一位盟友在组建由硅谷高管组成的"作战室"，游说董事会，并争取白宫支持；
- FT 此前还报道，董事会接触过 Arm CEO Rene Haas。

11/16，CNBC 报道：大股东 Altimeter Capital 和 Atreides Management 敦促董事会考虑所有领导层选项，其中包括让他回来。

Shuai 的说法有可靠来源，我的结论是错的。

## 原因

11/16 我用了三组检索词：

- "Jensen Huang reinstated OR comeback OR return as CEO Nvidia board shareholders November 2026"
- "Jensen Huang return Nvidia after resignation report"
- "黄仁勋 回归 英伟达"

返回的都是 11/9–11/10 回总部开会的报道。我没有换成"comeback + FT / confidants"这类检索词再查一次，就下了"没有可信报道"的结论。

## 之后的进展

11/17 财报当天，董事会表示一致接受其辞职，不打算让他复职（Yahoo Finance 财报直播）。

## 对结论的影响

- **建议和权重**：不受影响。11/16 的建议不依赖他是否回归，11/17 的 NVDA 决策规则里也没有这一条。
