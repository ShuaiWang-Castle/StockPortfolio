# Anthropic 的企业客户为什么愿意继续付钱

Codex 由 OpenAI 开发。OpenAI 与 Anthropic 竞争。Anthropic 的经营和会计数字取自最终招股书，OpenAI 的分销数据取自其自行披露。数据截点为 2026-11-19 美东收盘。

**判断。** 持有 ANT 可以直接参与企业使用模型创造的利润。最能支撑这项判断的证据是大客户持续扩大用量，且越来越多客户同时购买平台和应用。决定股东回报的另一个条件是，Anthropic 在支付推理、下一代模型研发和云渠道费用后，每一美元新增收入还能留下多少现金。[424B4，第 140–145 页、附注 8](https://www.sec.gov/Archives/edgar/data/2130357/000162828026074944/anthropicpbc-424b4.htm)

## 客户在哪一层形成黏性

| 截至 2026-09-30 的发行人披露 | 对经营价值的含义 |
|---|---|
| 过去十二个月贡献至少 $100,000 收入的客户超过 11,900 家，一年前超过 950 家。本期该组贡献 $26.1B，占收入 74% | 客户按发行人能够识别的组织合并账户。即使少数大客户已经成熟，还有大量组织在真金白银地扩大部署。 |
| 当季上述客户中，超过 50% 同时使用 Claude Platform 和至少一种自家应用，2025Q4 约为 30% | 开发者把 Claude 接入产品，员工也在现成应用里工作。两处都要迁移，替换工作的范围更广。不同季度客户构成会变，此比较无法单独估计更换供应商的成本。 |
| 9 月末净收入留存率（NRR）约 900% | 以 2025Q3 已产生至少 $1 收入的合格客户为固定组，用同组 2026Q3 收入除以上年同期收入，剔除 Claude Pro、Max、Ultra 固定价订户。结果表示同组收入约为九倍，包含扩张、收缩和流失，不能由此推导客户续约率或未来九倍增速。 |
| 前九个月前五大终端客户占收入约 25%，同期 44% 的收入由云市场分销 | 前者衡量买方集中，后者衡量渠道集中，两者重叠。通过云市场销售时，Anthropic 与客户直接签约、自主定价、按总额确认收入，再向云商付费。许多大客户能较快缩减支出。 |

以上指标分别来自招股书术语、风险因素、MD&A 与收入确认政策。TTM 客户分层是发行人衡量企业采纳程度的代理指标。[424B4，第 2–4、61–62、140–141、149 页及 F‑22](https://www.sec.gov/Archives/edgar/data/2130357/000162828026074944/anthropicpbc-424b4.htm)

OpenAI 已有另一种分销优势。公司 9 月称其产品触达 250 万家企业，10 月称每周使用 ChatGPT 的人数超过 12 亿。消费者能把使用习惯带入工作，企业和开发者也可通过 API 或现成产品购买。两家公司各自披露的客户定义和计量周期不同，无法用这些数字计算相对市场份额或比较每个付费客户的利润。我的判断是两家都能有长期价值，谁能为企业以更低的总成本持续完成任务，谁就更有机会保住定价权。[OpenAI，2026-09-08](https://openai.com/index/the-work-now-within-reach/) · [OpenAI，2026-10-07](https://openai.com/index/gpt-6-for-everyone/)

## 每收一美元，多少能留给股东

2026 年前九个月，收入 $33.242B，附注 8 按职能列出的营业成本 $4.812B。两者推出毛利 $28.430B、毛利率 **85.52%**。营业成本包含向客户提供服务所用算力；研发费用 $19.240B 另含模型开发、研究和内部使用，销售与营销 $6.619B 另含渠道费和免费用户算力。两项合计消耗了收入的 77.79%，另有管理费用 $3.831B，最终 GAAP 经营亏损 $1.260B。就此可以从一手资料复核 Claude 的 85.5%，并补足上次 Codex 复核缺失的交叉检查。季度层面，Q3 的 GAAP 经营利润率约 −3%，调整后为 15%，较 Q2 调整后的 19% 回落，公司指向当季 $5.0B 较昂贵的短期算力。[424B4，第 142–143 页、附注 8 第 F‑41 页](https://www.sec.gov/Archives/edgar/data/2130357/000162828026074944/anthropicpbc-424b4.htm) · [11/19 首次复核](https://github.com/ShuaiWang-Castle/StockPortfolio/blob/0c614ab1adf3c68639a9fff4b19590b06622b2c0/codex_review_20261119/ANT.md)

2026-09-30 已签约、尚待履约的客户收入（RPO）为 $13.8B，预计约 75% 在次十二个月确认。客户日后按用量购买会另外形成收入。公司列出的采购与租赁承诺约 $900.9B，其中自 9 月末起十二个月约 $70.7B 到期，$186.2B 有解除权或生效先决条件。客户可以按需付费，公司往往提前 12–18 个月锁定算力，合同两端的期限错配使利用率、采购价格和销售价格共同决定现金流。RPO 与采购额分属已签收入和合同支出，直接相减无法得到资金缺口。[424B4，第 140、178–179 页及附注 2 第 F‑27 页](https://www.sec.gov/Archives/edgar/data/2130357/000162828026074944/anthropicpbc-424b4.htm)

## 与 NVDA、AMZN、GOOGL 的关系

Anthropic 披露训练与推理可分别调度到 NVIDIA GPU、AMD GPU、AWS Trainium、Google TPU，并与 NVIDIA 共同优化后续硬件。AI 总用量增长有利于 NVIDIA 销量，模型商跨架构采购则要求 NVIDIA 持续赢得单位任务成本、性能和交付的比较。即使 Claude 市占提高，新增利润在芯片厂、云商和模型商之间怎样分配，仍取决于议价能力。持有 NVDA 与 ANT 是对这两种利润来源同时下注，两者也会共同受 AI 支出收缩影响。[424B4，第 141–142、213–214 页](https://www.sec.gov/Archives/edgar/data/2130357/000162828026074944/anthropicpbc-424b4.htm)

按本次发行和配售完成后的已发行股本口径，Amazon 与 Google 各持有 ANT 的 14.6% 和 13.4%。买入这两家母公司的一美元，折算成多少 ANT 股权，还要用母公司所持股数乘以 ANT 股价，再除以母公司自身市值。另有云分销和基础设施业务带来的利润联系。因此配置 ANT 同时提高了组合对模型公司直接收益和已有商业关系的依赖。[424B4，The Offering、Certain Stockholders](https://www.sec.gov/Archives/edgar/data/2130357/000162828026074944/anthropicpbc-424b4.htm)

**下次财报怎样更新判断。** 我会按同一口径重看大客户收入及交叉使用比例，观察固定客户组的扩张是否延续；再比较 GAAP 经营利润率、研发和渠道费用占收入比例，以及即将到期的采购义务。如果收入继续扩大、费用占比也下降，十年估值模型里的成熟现金流率才得到更直接的支持。收盘价、反向 DCF 与不同资金来源的组合计算见[本次研究汇总](README.md)。
